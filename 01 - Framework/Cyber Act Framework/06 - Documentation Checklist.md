# Documentation Checklist

> **Author Verification Standard:** Cyber Act Module Authoring Checklist  
> **Version:** 2.0  
> **Status:** Active Standard

---

## Content
- [ ] Includes formal engineering definition and one-line summary.
- [ ] Explains technical purpose, problem solved, and historical origin.
- [ ] Provides real-world analogy and low-level technical mental model.
- [ ] Maps domain placement, prerequisites, and enabled topics.

---

## Structure
- [ ] Strictly follows the 9-part Universal Engineering Framework.
- [ ] Implements standardized H1 ➔ H4 heading hierarchy.
- [ ] Uses horizontal rules (`---`) to separate major H2 sections.
- [ ] Includes complete metadata card block at the document top.

---

## Formatting
- [ ] Adheres to Documentation Style Guide spacing and paragraph rules.
- [ ] Uses GitHub alert callouts (`[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`).
- [ ] Uses tables exclusively for comparisons, code mappings, and feature matrices.
- [ ] Formats all code blocks with explicit syntax language identifiers.

---

## Commands
- [ ] Every CLI tool is documented in an individual reference block.
- [ ] Command blocks specify Purpose, Syntax, Parameters, Input/Output, and Example Usage.
- [ ] All command parameters are verified for accuracy.

---

## Labs
- [ ] Practical labs follow the Practical Lab Standard format.
- [ ] Commands are fully executable and copy-pasteable.
- [ ] Includes explicit Expected Output text blocks.

---

## Security
- [ ] Defines threat model and attack surface.
- [ ] Details specific attack vectors and vulnerability mechanics.
- [ ] Provides detection opportunities and MITRE ATT&CK mappings.
- [ ] Includes actionable security hardening checklist.

---

## Engineering
- [ ] Analyzes architectural design rationale and philosophy.
- [ ] Features technology comparison matrix against competing tools.
- [ ] Details performance trade-offs, limitations, and selection guidelines.

---

## References
- [ ] Provides quick reference cheat sheet.
- [ ] Lists critical file paths, environment variables, default ports, and error codes.
- [ ] Includes official documentation links and standard RFC references.
